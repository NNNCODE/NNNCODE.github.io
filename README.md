# NNNCODE.github.io

The public pages of Kenning, a hover dictionary for people learning English.

- `lexi-hover/` is the website: the homepage, the privacy policy, and the page that opens when
  Kenning is removed. It is served at <https://nnncode.github.io/lexi-hover/>.
- `kenning-voices/` holds the pronunciation files, one for each word in Kenning's dictionary
  (CC0, see `kenning-voices/LICENSE`). They are served at <https://nnncode.github.io/kenning-voices/>.

Until 2026-11-10 these were two repositories, `NNNCODE/lexi-hover` and `NNNCODE/kenning-voices`;
both histories are part of this one. The root page opens the homepage.
